# Second Office Website

This is the official production website for Second Office – Your Digital Department.

## Structure
- `/index.html` – Homepage
- `/services.html` – Services overview
- `/portfolio.html` – Portfolio
- `/about.html` – Team & company
- `/packages.html` – Pricing packages
- `/contact.html` – Contact form
- `/privacy.html` – Privacy policy
- `/terms.html` – Terms & conditions
- `/admin/` – Admin dashboard (login, leads, reviews, etc.)
- `/css/` – All stylesheets
- `/js/` – All frontend JavaScript
- `/backend/` – Node.js + Express backend

## Technologies
- HTML, CSS, JavaScript (vanilla)
- Node.js + Express
- Supabase (PostgreSQL)
- Google Analytics 4
